MarkDown++ Editor is a free Windows app for viewing, creating and editing Markdown files.

  • Open a single file or a whole folder and browse all its Markdown files.
  • Work on several files at once in tabs.
  • Edit directly in the formatted view, or switch to the source view.
  • Formatting toolbar, zoom, light and dark themes that follow Windows.
  • Live character and word counts in the status bar.

Get it from the Microsoft Store.
