Report it on the MarkDown++ issues page. Please describe what you did, what you expected, and what happened instead.

Keyboard shortcuts

  • Ctrl+N new file, Ctrl+O open file, Ctrl+Shift+O open folder
  • Ctrl+S save, Ctrl+Shift+S save as, Ctrl+W close tab
  • Ctrl+E switch between formatted and source view
  • Ctrl+Tab next tab, Ctrl+Shift+Tab previous tab
  • Ctrl+Plus and Ctrl+Minus zoom, Ctrl+0 reset zoom, or Ctrl+mouse wheel
