# MarkDown++ Change Log

All notable changes to MarkDown++ Editor, newest first.

## 1.1.0 (October 4, 2026)

### Added
- The folder you had open is reopened automatically the next time you start the app.
- When a file open in a tab is changed by another program, the app tells you and asks whether to reload it (like Notepad++). It checks when you switch to the tab and when you come back to the app window. Your unsaved changes are never replaced without asking.
- If an open file is deleted, renamed or moved by another program, the app tells you and keeps the text open so you can save it again.
- Right-click a file or folder in the file list to **Copy Path** to the clipboard. Files also get an **Open** option.

## 1.0.0 (October 1, 2026)

First release on the Microsoft Store, as **MarkDown++ Editor**.

### Added
- Microsoft Store package, with `.md` and `.markdown` files opening in the app from File Explorer.
- App icon and Store listing.
- Privacy policy, support page and website.

## 0.3.1 (October 1, 2026)

### Changed
- File list shows blue file icons, and yellow folder icons instead of arrows.

## 0.3.0 (October 1, 2026)

### Added
- Zoom with Ctrl+Plus, Ctrl+Minus and Ctrl+mouse wheel; Ctrl+0 or a click on the zoom level in the status bar resets it.

### Changed
- The file list can be resized by dragging its edge, and shows full file names.
- Folders start collapsed when a folder is opened.
- Larger default text in the formatted view (20 px), with headings scaled to match.

## 0.2.0 (October 1, 2026)

### Added
- Open a single file or a whole folder; the folder's Markdown files are listed on the left.
- Tabs for working on several files at once, with unsaved-changes markers, drag to reorder and middle-click to close.
- Edit directly in the formatted view, or switch to the source view (Ctrl+E).
- Formatting toolbar: bold, italic, headings, lists, quotes and links.
- New, Save and Save As, with a reminder to save before closing.
- Character and word counts in the status bar.
- Light and dark themes that follow Windows.
- Delivered as a single EXE, no installer needed.

## 0.1.0 (October 1, 2026)

- First preview: app window and layout.
