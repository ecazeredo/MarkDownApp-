# MarkDown++

A lightweight Windows app to view, create and edit Markdown files.

## Try the latest build

1. Open the **Actions** tab of this repository and pick the latest green **Build Windows installer** run.
2. Download **MarkDownPlusPlus-Windows-installer** at the bottom of the page and unzip it.
3. Run the `MarkDown++_x.y.z_x64-setup.exe` inside. Windows may show a SmartScreen warning for unsigned test builds: click **More info**, then **Run anyway**.

## Development

Built with [Tauri 2](https://tauri.app), TypeScript and Vite.

```sh
npm install
npm run tauri dev     # run the app
npm run tauri build   # build the Windows installer
```
